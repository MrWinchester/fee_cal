# 费用计算器 - 抖音小程序

一个功能完整的费用计算器抖音小程序，支持多种费用项目的自动计算和后台价格管理。

## ✨ 功能特性

### 📊 费用计算（主页）
- **自动面积计算**：输入长度和宽度，自动计算平米数
- **8种费用项目**：
  1. 切割费（按平米）
  2. 加工费（按项）
  3. 打包费（按次）
  4. 运费（按公里）
  5. 卸货搬运（按次）
  6. 安装（按平米）
  7. 灯带（按平米，含安装）
  8. 其他（直接金额）
- **实时计算**：输入即计算，无需点击按钮
- **明细展示**：清晰的费用明细和总计
- **一键重置**：快速清空所有输入

### 🔧 后台管理
- **安全登录**：管理员账号密码验证
- **价格管理**：修改各项费用单价
- **默认重置**：一键恢复默认价格
- **数据持久化**：价格配置保存在本地

### 📱 移动端优化
- **响应式设计**：使用 rpx 单位适配不同屏幕
- **卡片式布局**：清晰的视觉层次
- **友好交互**：实时反馈和操作提示

## 🚀 快速开始

### 前置要求

- 抖音小程序开发者工具
- 抖音开放平台账号（可使用测试号）

### 安装步骤

1. **克隆项目**
   ```bash
   git clone https://github.com/MrWinchester/fee_cal.git
   cd fee_cal
   ```

2. **导入项目**
   - 打开抖音小程序开发者工具
   - 选择"导入项目"
   - 选择项目目录
   - 填写 AppID（或使用测试号）

3. **编译运行**
   - 点击开发者工具的"编译"按钮
   - 在模拟器中查看效果

## 📖 使用说明

### 计算费用

1. 打开小程序，默认进入"费用计算"页面
2. 输入长度和宽度（自动计算面积）
3. 输入各项费用的数量/次数/公里数
4. 查看实时计算的费用明细和总计
5. 点击"重置"按钮清空所有输入

### 管理价格

1. 点击底部 TabBar 的"后台管理"
2. 首次进入需要登录：
   - 账号: `admin`
   - 密码: `Shuitou128`
3. 点击任意价格项进行修改
4. 输入新单价并确认
5. 修改后的价格立即生效

## 🌟 核心特性

### 三种计费方式

1. **按面积计算** (`area`)
   - 切割费、安装、灯带
   - 根据长×宽自动计算面积
   - 无需手动输入

2. **按数量计算** (`quantity`)
   - 加工费、打包费、运费、卸货搬运
   - 手动输入数量/次数/公里数
   - 单价 × 数量 = 费用

3. **直接金额** (`direct`)
   - 其他费用
   - 直接输入金额
   - 灵活处理特殊费用

### 数据持久化

- 使用 `tt.storage` 保存价格配置
- 登录状态持久化
- 关闭小程序后数据不丢失
- 支持重置为默认配置

### 实时计算

- 输入即计算，无延迟
- 修改尺寸自动更新按面积计费项目
- 清晰的费用明细展示
- 醒目的总计显示
